# 사진 수집·라벨링 상태

현재 후보는 net=1085, lookalike=366, other=259입니다. 폴더 이름은 검색 범주이며 검증된 정답이 아닙니다. `candidates.json`에는 사진별 출처·저작자·라이선스·수정된 파일의 SHA-256·dHash가 있습니다. Release 자산에는 이 목록에 기록된 사진만 포함합니다.

사진은 EXIF 방향을 반영해 RGB로 바꾸고 긴 변 최대 768px, JPEG 품질 91로 다시 저장했습니다. 이 변환 사실과 각 사진의 출처·라이선스를 재배포 시 함께 유지하세요. 사진의 권리는 각각의 저작자에게 있습니다. 프로젝트 코드의 상태와 사진의 라이선스는 별개입니다.

`box_suggestions.json`은 Grounding DINO의 자동 박스 제안으로 정답이 아닙니다. `rejected.json`은 초기 접촉 시트 검토에서 제외한 후보입니다. 나머지는 모두 승인된 것이 아닙니다.

검수자는 각 후보의 실제 물체와 박스 전체를 확인하고 `data/review.json`에 다음처럼 기록해야 합니다. 박스는 정규화된 `[왼쪽, 위, 오른쪽, 아래]`입니다. 음성 사진의 boxes는 반드시 빈 목록이어야 합니다.

```json
{
  "후보의_id": {
    "accepted": true,
    "reviewed": true,
    "boxes": [[0.1, 0.2, 0.8, 0.9]]
  }
}
```

`prepare_dataset.py`는 SHA-256과 dHash로 중복을 제외하고 500/300/200장을 선택합니다. 범주마다 80%/20%로 나누어 합계 학습 800장, 테스트 200장을 만듭니다. 유사한 연속 촬영·동일 장면은 dHash만으로 모두 제거할 수 없으므로 검수 시 함께 확인해야 합니다. 아직 확정 분할과 그물 전용 학습은 하지 않았습니다.

수집 스크립트는 공개 Openverse/Wikimedia 데이터를 사용합니다. 재실행해도 같은 검색 결과나 다운로드 가능성을 보장하지 않습니다. 서비스가 제한하면 중단하고 나중에 재시도하세요.
