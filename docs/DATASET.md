# 사용 중인 데이터

현재 학습 원천은 BePLi v2 공식 배포본의 실제 해변 사진과 수작업 fishing_net COCO 라벨입니다. https://doi.org/10.17882/96963 · CC BY-NC-SA 4.0.

직접 촬영·생성 사진·과거 검색 후보는 사용하지 않습니다. 원본 3,722장 중 fishing_net 포함 사진은 867장입니다. 공식 9.5 GB 압축은 바탕화면 프로젝트의 `data/labeled_sources/BePLi_v2/source/106157.tar.gz`에 보관합니다. SHA256: `5d27c9b103710223f928346f096a68d3f53211b1a30ce34d7815c8049458d711`.

현재 선별은 1,000장(그물 포함 500·rope/other_string 음성 300·기타 음성 200)입니다. 학습 700·검증 100·테스트 200으로 나눕니다. 초기 전체 화면 20회 학습 뒤 실제 객체 영역으로 잘라 8회 추가 학습했습니다. 현재 학습 사진 중 668장에만 자르기를 적용했고 검증·테스트는 전체 원본입니다. 두 단계 전체에서 사용한 고유 학습 원천은 1,022장입니다.

이전 테스트 200장은 초기 실험 실패 후 최종 테스트에서 제외했습니다. 최종 테스트는 그물 포함 50장과 그물 없는 150장입니다. `data/bepli_manifest.json`과 `data/bepli_dataset_report.json`에 사진별 출처·박스·해시·제외 ID를 기록합니다. 초기 실험 보고서는 `bepli_baseline_*` 파일로 보존합니다.

`tools/data.py`가 공식 다운로드·압축 해제·중복 검사·선별·라벨 변환을 수행합니다. 원본 train/val/test 경계는 유지합니다. SHA256과 dHash로 중복을 거르지만 동일 장면을 모두 보장하는 검사는 아닙니다. 그물이 없는 사진은 별도 클래스를 만들지 않고 빈 라벨 파일을 사용합니다.

Littora 등 Roboflow 자료는 인증 문제로 아직 다운로드하지 않았습니다. 이전 Openverse/Flickr/Wikimedia 검색 후보와 Grounding DINO 제안은 현재 학습에서 제외한 기록이며 `data/raw` 등 원본 보관본을 삭제하지 않았습니다. `CANDIDATE_SOURCES.csv`와 검색 관련 JSON은 그 과거 출처 기록입니다. 이전 수집 스크립트는 Git의 `android-v0.2.0` 태그에서 볼 수 있습니다.
