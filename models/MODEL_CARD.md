# NetRobot BePLi focus v2 — 시험용 그물 모델

이 모델은 아직 실사용 수준에 미달합니다. 자동 주행·집게 제어에 사용하지 않습니다.

- 클래스: net (BePLi의 fishing_net), YOLOv8n, FP32 ONNX, 입력 640×640, NMS 제외.
- 데이터: BePLi v2 공식 수동 라벨. https://doi.org/10.17882/96963 (CC BY-NC-SA 4.0).
- 현재 구성: 원천 사진 1,000장 = 그물 500, rope/other_string 음성 300, 기타 음성 200.
- 최종 단계: 학습 700장, 검증 100장, 새 테스트 200장(그물 포함 50장, 없는 사진 150장).
- 초기 전체 화면 학습 20회 뒤 실제 사진의 객체 영역을 잘라 8회 추가 학습. 생성된 그물 사진은 사용하지 않음. 일반 Mosaic/색상 학습 증강은 적용함.
- 두 단계가 본 고유 학습 원본은 합계 1,022장. 현재 학습 원본 700장 중 668장은 객체 영역으로 잘랐고, 검증/테스트는 원본 전체 화면을 유지함.
- 초기 실험에서 평가한 테스트 200장은 최종 테스트 후보에서 제외함. 제외 ID는 data/bepli_dataset_report.json에 기록함.
- 검증은 640 입력에서 crop best/last 후보 중 mAP50가 높은 last.pt를 선택했고, 그 다음 새 테스트 200장을 1회 평가함.

## 최종 테스트

| 지표 | 결과 |
| --- | ---: |
| 정밀도 | 12.11% |
| 재현율 | 13.46% |
| mAP50 | 4.06% |
| mAP50-95 | 1.53% |

Ultralytics의 기본 평가 절차에서 계산한 값입니다. 앱은 기본 신뢰도 40%, NMS IoU 0.45를 사용합니다. 박스의 %는 모델의 개별 감지 점수입니다.

## 실행 검사와 제한

- 검증 사진 2185에서 신뢰도 0.417, 실제 라벨과 IoU 0.513인 감지 1건을 확인함. 별도로 본 큰 그물 검증 사진 4장 중 3장은 기본 임계값에서 놓침.
- ONNX 구조·가중치 유한값 검사, PyTorch/앱 내 WASM 출력 비교 통과: 박스 최대 차이 0.001465px, 신뢰도 최대 차이 약 0.00000206.
- 비교 실행은 Windows Node WASM입니다. Android에서 모델 속도·정확도는 아직 검증하지 못함.
- v0.1.0의 FLOW 카메라 영상 수신은 2026-11-24 사용자 기기에서 확인됨. v0.2.0 실기 검증은 별도 필요함.
- 해변의 작은 폐그물이 주된 데이터입니다. 다른 배경·그물 재질·실내·조명·로봇 낮은 시점에서의 일반화는 검증하지 못함. 오탐과 누락이 많음.
- 모터는 현재 모의 조종이며 드론 비행 명령은 보내지 않음.
