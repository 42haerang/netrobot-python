카메라 및 연결

영상과 그물 감지, 조종을 이 사이트 안에서 사용합니다. 모터는 HC-06 연결과 활성화 후 실제로 움직입니다.

사진·영상은 이 노트북의 Python OpenCV로 처리하며 인터넷으로 전송하지 않습니다.

브라우저 접근(CORS)을 허용한 JPEG 주소가 필요합니다. HTTPS 사이트에서는 HTTPS 주소를 사용하세요.

FLOW의 UDP 영상은 Python 수신부가 브라우저용 JPEG로 바꿉니다. 드론 Wi-Fi에 연결한 기기에서 python tools/build.py control을 실행하고 출력된 조종 주소를 여세요. 웹사이트만으로 UDP 카메라에 직접 연결되지는 않습니다.

HC-06 · 실제 모터 연결

연결 후 화면의 모터 활성화를 누르세요. 통신이 끊기면 정지하고, 자동으로 다시 움직이지 않습니다.

모델: models/net.onnx · Python OpenCV DNN · 박스와 점수도 OpenCV로 표시합니다.

화면: 브라우저 Python · 감지·모터 통신: 노트북 Python
